# Plugin Figma — Girassol

Gera o arquivo visual completo em qualquer documento Figma:

- **00 · Capa** — 1600×900;
- **01 · Design System** — cores, tipografia, botões, pills, card e marca;
- **02 · Telas** — 8 telas 390×844 (Home, Autoestudo, Modelos, Treinar, Codex, Chat, Llamatik, Ajustes);
- **03 · Fluxo** — pipeline de autoestudo e decisões.

## Como usar

1. Abra o Figma (web ou desktop) em um arquivo novo.
2. Menu **Plugins → Development → Import plugin from manifest…**
3. Selecione `design/plugin/manifest.json`.
4. Rode **Plugins → Development → Girassol Design System**.
5. Aguarde alguns segundos; as 4 páginas são criadas.

O plugin usa a fonte Inter (fallback Roboto/Arial) e não precisa de imagens externas: a marca é vetorial.
